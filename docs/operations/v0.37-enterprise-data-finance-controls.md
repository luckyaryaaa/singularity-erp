Tanggal engineering closure: 28 Juli 2026

## Scope

Release ini mengonsolidasikan migration 065–069:

- field encryption foundation dan controlled key rotation;
- data retention lifecycle dan legal hold;
- journal coding block;
- GL-to-tax reconciliation;
- financial-report prepare, review, sign-off/reject.

OpenAPI 1.3 mendokumentasikan endpoint Finance baru. Retention Workbench masuk
visual baseline desktop/mobile.

## Control posture

- AES-256-GCM memakai purpose/scope AAD, key ID, previous-key ring, blind index,
  dan rotation ledger.
- Retention hanya menjalankan SQL statis untuk enam resource teknis allowlisted.
- Eksekusi retention menuntut preview yang cocok, recent MFA, idempotency, exact
  candidate count, bounded batch, dan alasan.
- Coding block mendukung cost center, profit center, dan project WBS.
- Rekonsiliasi pajak menghitung selisih GL terhadap tax ledger dan menjadi
  bagian closing cockpit.
- Financial report memakai immutable source snapshot, version, maker-checker,
  dan SoD.
