# v0.39.0 — Finance End-to-End Closure

**Tanggal:** 28 Juli 2026 · **Migration:** 074 · **API:** 1.4

## Outcome

Stage 3 Finance End-to-End selesai pada lingkup engineering:

- coding block fail-closed dari transaksi sampai journal line;
- enam reconciliation evidence dengan maker-checker;
- financial statements Prepare → Review → Sign-off;
- immutable period-close package dan reopen lifecycle;
- UI operator desktop/mobile, authorization, RLS, audit, dan OpenAPI.

Status ini tidak menyatakan rekonsiliasi bisnis aktual telah disetujui dan tidak
menggantikan UAT atau Owner production sign-off.

## Kontrol utama

| Area | Kontrol |
|---|---|
| Journal dimensions | Default `HARD`; akun P&L tanpa dimensi wajib ditolak |
| Auto posting | Cost/profit center aktif di-resolve per legal entity/cabang dan disimpan pada snapshot |
| Policy maintenance | Version, optimistic update, reason, permission, audit |
| Reconciliation | BANK/INVENTORY/PAYROLL/TAX/AR/AP; immutable snapshot + SHA-256 |
| Segregation of duties | Approver tidak boleh sama dengan maker |
| Financial report | Maker ≠ reviewer ≠ signer; hash dan balance diverifikasi |
| Period close | Close wajib reason + idempotency serta enam latest evidence APPROVED, hash valid, bukan NOT_RUN |
| Reopen | Evidence lama tetap ada dan berstatus `REOPENED` |
| Database | RLS fail-closed dan runtime least privilege |

## Gate manusia tersisa

1. Jalankan transaksi UAT oleh 13 role pada release SHA yang sama.
2. Finance menyiapkan dan checker berbeda menyetujui enam evidence aktual.
3. Tutup satu periode UAT, sign-off official report, lalu verifikasi reopen
   hanya jika skenario retest membutuhkannya.
4. Tutup `SEC-UAT-001` secara manual, training, DR RTO/RPO, dan offsite proof.
5. Owner memberikan final sign-off sebelum VPS/domain ERP diaktifkan.
