## Identity controls

- Owner tidak dapat direset dari aplikasi.
- Security Admin/Owner dapat menjadi maker reset administrator; checker dan
  eksekutor wajib Owner berbeda dengan maker.
- Recent MFA, alasan, expiry 30 menit, duplicate pending guard, row lock, dan
  audit tanpa secret diterapkan.
- Tautan reset sekali pakai menggantikan password sementara. Password lama
  langsung tidak berlaku dan token hanya tersimpan SHA-256.
- MFA enrollment menerbitkan sepuluh recovery code sekali pakai; regenerasi
  membutuhkan faktor aktif dan mencabut set lama.
- Perubahan faktor mengirim notifikasi keamanan.
