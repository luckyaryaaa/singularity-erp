# v0.42.0 — Unified Work Item Engine

**Tanggal:** 29 Juli 2026
**Cakupan blueprint:** §4.4 Work Item / Task Engine, §5.2 Workspace critical updates
**Migration:** 077 `unified_work_items`

## 1. Tujuan

Sampai kini "My Work" hanya AGREGASI read-only dari `business_documents`,
`background_jobs`, dan `notifications` — tidak ada objek pekerjaan yang bisa
ditugaskan, diklaim, di-SLA-kan, didelegasikan, dan diaudit lintas modul; membaca
notifikasi bahkan keliru dianggap "menutup pekerjaan". Wave ini menutup P1 audit
"Unified Work Item" dengan satu engine formal.

## 2. Model data (`work_items`)

| Aspek | Keputusan |
|---|---|
| Jenis | APPROVAL, EXCEPTION, REVIEW, CORRECTION, TASK, FOLLOW_UP |
| Siklus hidup | OPEN → CLAIMED → IN_PROGRESS → RETURNED / ON_HOLD → DONE / CANCELLED |
| Penerima | `assignee_user_id` dan/atau `assignee_role` (pool bila keduanya kosong) |
| Prioritas / risiko | LOW..URGENT / LOW..HIGH |
| SLA | `due_at` eksplisit atau diturunkan dari `sla_minutes` |
| Delegasi | `delegated_to`/`by`/`at`/`reason` (substitusi/cuti) |
| Eskalasi | `escalated` + `escalated_to`, menaikkan prioritas ke HIGH |
| Evidence | `evidence` jsonb + `completion_note` |
| Sumber | `source_module`/`source_entity_type`/`source_entity_id` (generik, tanpa FK) |
| Concurrency | `version` optimistic lock pada setiap transisi |
| Isolasi | RLS `branch_scope` (`app_branch_visible`) |

## 3. Perilaku kunci

- **Notifikasi ≠ penyelesaian.** Menutup pekerjaan menuntut transisi eksplisit
  ber-`version`, bukan membaca antrean.
- **Klaim menghormati penargetan.** Item ber-peran hanya dapat diklaim peran yang
  cocok; pool bebas hanya bila item tidak ditargetkan ke pengguna maupun peran.
- **Kepemilikan ditegakkan.** Hanya assignee/claimer/delegate/creator (atau peran
  lintas cabang) yang boleh menutup/mengubah — pola OWN_RECORD di repository, di
  atas guard `dashboard.view` dan RLS.

## 4. Endpoint & UI

- Router Workspace bertambah dari 3 → 7 handler bounded (create, list, complete,
  dan satu handler alternation untuk claim/start/return/hold/cancel/delegate/
  escalate). Total baseline authorization matrix **302 handler**. OpenAPI menambah
  operasi Work Item ber-cookieAuth.
- **My Work** kini menampilkan bagian Work Item nyata (Ditugaskan ke saya, Sedang
  saya kerjakan, Didelegasikan ke saya, Dikembalikan untuk revisi) dengan aksi
  lifecycle langsung (klaim/mulai/selesai/kembalikan).

## 6. Integrasi lanjutan (belum dikerjakan)

Emisi otomatis work item dari engine domain — approval workflow, WMS task engine
(075), rekonsiliasi Finance (074) — sehingga setiap kejadian yang menuntut
tindakan manusia otomatis menjadi work item terlacak. Ini pekerjaan integrasi
per-modul berikutnya (idealnya lewat transactional outbox / domain event §4.5).

## 7. Gate manusia (tidak berubah)

UAT 13 role, security retest manual, persetujuan enam rekonsiliasi, training, DR
RTO/RPO, offsite proof, dan Owner sign-off tetap fail-closed. Status v0.42.0
adalah engineering release candidate, bukan izin aktivasi produksi.
